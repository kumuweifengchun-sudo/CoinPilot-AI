# Windows 安装包验收

构建和源码测试不能代替本清单。使用独立 Windows 10/11 x64 测试用户或虚拟机，不在日常账户安装测试包、修改启动项或操作真实凭据。记录系统、安装包版本和 SHA-256，以及每项实际结果；未执行项标记“未验证”。

## 首次安装

- 环境不安装 Python、Qt 或 uv。运行 Setup，确认简体中文向导、无管理员提权、默认当前用户目录及可修改路径。
- 分别验证默认目录与含中文、空格的目录；目录中同时有 EXE 与 `_internal`。保留各次安装日志（Setup 支持 `/LOG="日志路径"`）。
- 默认创建开始菜单和桌面快捷方式；取消桌面选项后不创建桌面快捷方式。快捷方式目标、工作目录和卸载登记均指向实际安装目录。
- 完成页面运行、桌面及开始菜单启动都默认打开迷你窗口；图标、Inter 字体、中文对话框与 100%—200% DPI 正常。
- 打开设置、工作台和托盘，反复启动只唤回已有实例；源码与 EXE 混合验证另在有开发环境的测试用户执行。

## 覆盖安装和升级

- 在测试用户配置中保存可辨识的虚构数据、数据库记录和画线；测试凭据仅使用虚构字符串。记录文件哈希与凭据存在状态，不输出凭据内容。
- 程序运行时开始覆盖安装，确认提示从托盘退出，主进程未被强制终止；退出后重试可继续，不能要求重启后覆盖。
- 在程序运行时执行 `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART`，必须失败退出且不关闭应用、不修改安装文件。安装日志应指明占用。
- 同版本覆盖一次，再用测试版本号构建包升级一次，确认只保留一个卸载入口、沿用原目录和已选任务；配置、数据库和凭据仍在，快捷方式可启动。
- 安装取消和安装目录不可写时必须明确失败，不声称成功。关闭所有窗口但保留托盘时仍必须阻止覆盖。
- 旧单文件版退出后安装；默认数据可继续使用，旧启动项不自动改写。在新程序保存开机启动后，启动项应指向新 EXE 并保留配置及缓存参数。
- 从 Crypto Widget 安装版更名升级：确认复用原 AppId 与安装目录，旧 EXE 运行时阻止升级；退出后旧入口和快捷方式被移除，新名称及快捷方式可用，配置、数据库和凭据继续读取。

## 程序内更新（隔离用户／虚拟机）

- 使用包含更新功能的旧版本，确认启动后自动检查、每 6 小时再次检查、关闭自动检查后停止定时任务，手动检查仍可用。
- 正式版发现、当前已是最新版、预发布忽略、网络断开、代理失效及发行源限流时，程序继续盯盘且错误可重试。
- 新版本必须同时发布匹配名称的安装包与 `.sha256`。测试缺少附件、SHA-256 错误、文件截断和不受信任重定向；必须阻止安装并清理未完成下载。
- 下载时关闭更新窗口，确认下载继续；取消下载后迟到响应不能变为可安装状态；修改代理或退出程序时取消在途下载。
- 确认安装前核对当前交易请求已完成。取消确认不得退出；确认后助手应校验并锁定文件，只有原进程完全退出后才能打开安装向导。
- 助手启动失败或校验失败时，主程序应继续运行。安装向导取消或失败时，保留用户数据，原版本仍可重新启动。
- 完成升级后检查版本号、安装目录、配置、画线、数据库及凭据，再完成上面的覆盖安装验收；不得用测试中未执行安装的助手验证替代此流程。

## 卸载

- 运行中卸载必须要求先从托盘退出；静默卸载应失败而不结束应用。
- 在测试账户中依次验证：没有 `CryptoWidget` 启动项、启动项指向本安装 EXE（含引号与配置参数）、指向其他目录同名 EXE、指向源码 `pythonw.exe`。仅第二种应被移除，其他应用启动项不受影响。
- 通过系统卸载入口完成卸载：程序文件、快捷方式和卸载登记移除，配置、SQLite、缓存及虚构凭据保留。安装目录中新建的非安装器管理文件应保留。
- 再安装后原数据可用；测试结束后仅在隔离账户中手动清理测试数据和测试凭据。

## 开发机补充检查

```powershell
uv run --locked --group dev pytest -q
.\tools\test_installer.ps1 -IsccPath "D:\Inno Setup 6\ISCC.exe"
.\tools\build_installer.ps1 -IsccPath "D:\Inno Setup 6\ISCC.exe"
uv run --locked python tools/smoke_test.py --exe "测试安装目录\coinpilot-ai.exe"
```

`test_installer.ps1` 编译并执行共用 Inno 脚本的专项自检，覆盖中文／空格／大小写／引号／参数路径、其他应用及其他目录启动项保护，以及文件占用和运行中 EXE 检测。它仅创建随机临时注册表键并在退出前清理，在 `InitializeSetup` 阶段返回退出，不执行安装；报告保存在 `build/installer-tests/<唯一编号>/`。统一构建入口也会运行此检查。

启动检查使用临时配置和独立凭据命名空间，可能访问公开行情，不发送账户交易；内部诊断模式禁用自动更新检查，并验证字体、Qt 中文翻译和应用图标确实加载成功。发布未包含代码签名。未完成以上隔离环境清单前，只可标记“已构建、已通过启动检查”，不可标记“安装生命周期已验收”。
