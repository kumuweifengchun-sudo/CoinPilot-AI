# CoinPilot AI v0.2.3

本版本修复 ATR 等副图指标缺少光标取值的问题，为颜色设置增加直观的色块预览，并改进 OI/Funding 快照显示。

## 修复与改进

- 修改：ATR、RSI、MACD 及自定义副图显示十字光标所在 K 线的指标值，移开光标后显示最新值。
- 修改：多输出指标分别显示名称和对应数值；预热不足或数据缺失显示“—”，保留有效零值。
- 修改：指标整体颜色、逐输出颜色、EMA 和绘图颜色按钮统一在颜色代码左侧显示色块，选色后同步更新。
- 修改：颜色代码使用主题文字色，选择黑色或白色时仍保持可读。
- 新增：副图取值回归用例，以及 ATR 悬停和颜色设置的离线界面检查。
- 修改：OI/Funding 打开或切换品种时安排刷新，展示最新快照、采样时间与请求失败状态，单个采样点也能绘制。
- 修改：衍生品副图与主图时间轴对齐，明确标注仅包含本次运行采样，不补取启动前的历史；过期指数价格不参与最新基差计算。

## 验证与范围

- 完整质量检查通过：标准类型检查零诊断，822 项自动化测试通过。
- 已实际核对 ATR 悬停取值、颜色色块，以及 OI/Funding 单点、短序列、无历史与请求失败的离线截图；测试使用临时数据库和模拟行情，未进行交易所接口连通性验收。
