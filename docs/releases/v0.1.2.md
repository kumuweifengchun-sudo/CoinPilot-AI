# CoinPilot AI v0.1.2

本版本补齐 OKX K 线周期，并改进长历史图表、指标计算及回放回测的数据处理。

## 功能与改进

- 新增：完整 OKX K 线周期，共 27 个选项，覆盖秒线、分钟线、小时线、多日线、周线、月线和季度线。
- 新增：UTC+8 与 UTC+0 开盘版本选择；无后缀的长周期默认按 UTC+8 开盘，带 `utc` 后缀的周期按 UTC+0 开盘。
- 新增：周线和月线快捷按钮、完整周期菜单，以及图表日期跳转和指定时间范围历史加载。
- 新增：图表多空仓位工具、止盈止损与风险收益展示、已收盘走势复制和投影。
- 修改：按自然周、自然月与季度计算周期边界，适配缓存补缺、指标连续性、跨周期指标、提醒、历史回放和策略回测。
- 修改：行情采用列式数值缓冲区、共享 SQLite 缓存和有界内存窗口；历史查询、大范围计算及回测移至后台。
- 修改：十类指标支持增量计算，长跨度图表按显示周期和像素聚合，平移时复用绘图缓存。
- 修改：减少桌面后台绘制和安装包冗余资源，完善构建版本校验与发布脚本。

## 验证与范围

- 完整自动化测试：521 项通过。
- 版本递增后的版本与发行脚本测试：16 项通过；图表性能基准：10 项阈值全部通过。
- Windows 安装器安全自检通过；源码与打包 EXE 的悬浮窗、设置页、工作台启动退出，以及源码、EXE、混合启动的单实例唤回检查通过。
- OKX 公开接口：27 个周期均返回成功，开盘时间与本地周期边界计算一致。
- `1s` 历史范围受 OKX 限制，仅支持最近三个月；其他周期的实际历史覆盖取决于交易所与品种。
- 安装包不含代码签名。独立 Windows 用户或虚拟机中的首次安装、覆盖升级、程序内更新和卸载生命周期尚未验收；构建与启动检查不代表这些流程已验证。
