# 性能与资源占用

## 为什么迷你窗口仍有约 129MB

迷你模式只改变窗口显示内容。Python 解释器、Qt Widgets、字体、托盘、网络与行情订阅仍在同一个进程中运行；窗口高度与进程内存不成比例。优化前，默认启动还会导入工作台全部页面并启动其独立行情、K 线和衍生品服务。

工作台关闭仍然是隐藏，已打开的页面和未保存草稿继续存在。不能只根据一次任务管理器截图判断内存泄漏，也不能期待隐藏窗口立即回到首次迷你启动时的内存。

## 本次修改

- 工作台和旧设置窗口延迟导入。没有账户、没有启用提醒的首次迷你启动不启动工作台行情；已配置的账户、本地模拟及启用的提醒仍会恢复监控。打开工作台启动服务，重复打开不重复初始化订阅。
- Bar Replay、策略回测按首次访问创建，避免仅看盘时提前创建这些控件和历史缓存连接；创建后继续保留训练状态与草稿。
- 行情缓存最多保留 8 个闲置合约／周期组合。当前选择、多图、跨周期指标、启用的提醒、在途请求与补缺任务的数据受到保护。闲置组合的原始数据、数值序列、指标及索引一起淘汰，可重新下载；不截断当前图表的历史，不删除交易记录。
- 历史缺口查询只读取时间戳索引；历史读取不再先复制全部 JSON 查询结果；缓存写入使用生成器与紧凑 JSON，减少临时对象和新增缓存体积。
- 相同订单轮询结果不再重复写入订单及状态标记，减少 SQLite 写事务与 WAL 写入。
- Windows 分发移除未用到的软件 OpenGL、PDF 及部分图片插件、非中文翻译、项目展示图片和重复 ICO 源帧；保留运行需要的合并图标、字体、许可、中文翻译与 Windows TLS 后端。发行脚本的必需资源检查同步调整。
- 安装器升级阶段清理对应旧资源，防止覆盖安装后残留旧文件抵消体积优化；不清理用户配置、数据库、凭据或图标缓存。

未自动删除开发环境、旧构建包、用户历史缓存或业务记录。已有 SQLite 文件不会因新记录使用紧凑 JSON 而立即整体缩小。8 个闲置组合是数量上限，不是总字节上限；活跃图表的大量历史和用户记录仍会占用资源。

## 本机测量（2026-09-26）

Windows 11、Python 3.13、原生 Qt 窗口，临时配置及全新业务数据库，无账户／提醒，代理指向本机未监听端口以阻断外网。启动约 4 秒采样，正常退出；迷你模式每种构建测量 3 次，表中取中位数。

| 指标 | 优化前 | 优化后 | 变化 |
| --- | ---: | ---: | ---: |
| 现有／新构建目录版体积 | 98.27MiB | 65.39MiB | 减少 33.5% |
| EXE 迷你模式工作集（含共享页） | 139.55MiB | 136.66MiB | 减少 2.1% |
| EXE 迷你模式私有提交内存 | 74.17MiB | 71.26MiB | 减少 3.9% |
| 源码迷你模式工作集（含启动器） | 141.83MiB | 139.67MiB | 减少约 2.16MiB |

任务管理器截图的内存列与这里的工作集／私有提交量不是相同统计口径，不能直接把 129MB 与表格相减。实际占用还受字体缓存、DPI、网络结果、账户、行情历史与打开过的页面影响。本轮启动内存收益较小，主要收益是分发体积、避免多余后台工作和限制长期闲置缓存积累。

延迟创建研究页面的源码工作台单次样本：工作集 197.67 → 191.59MiB，私有提交量 120.33 → 114.92MiB。仅作为本机初步观察，不是稳定性能保证。

优化版安装包大小为 21,779,835 字节（约 20.77MiB），存放于 `artifacts/performance/installer/`；目录版位于 `artifacts/performance/dist/coinpilot-ai/`。原来的 `dist/` 保留用于对照。没有安装、发布或自动替换日常运行实例。

## 验证与复现

已通过完整 373 项测试。之后调整发行资源检查，再次通过 14 项发行脚本测试。目录版 EXE 和源码的迷你／设置／工作台启动退出、源码与 EXE 单实例唤回检查通过；工作台、训练及回测页面离线截图已检查。

5 万条历史的图表基准通过现有四项阈值：尾部更新 P95 0.010ms、2000 根可见 K 线完整重绘 P95 20.876ms、历史处理分片 P95 4.091ms；悬停 P95 在三个可见范围内均低于 8ms。这些是当前验证值，没有据此宣称相对旧版的绘制提速。

安装器编译成功。覆盖安装中的旧资源清理、卸载、真实账户与长期联网运行尚未在隔离用户／虚拟机验收，按 `packaging/windows/installer/VALIDATION.md` 继续检查。

```powershell
# 源码迷你模式；Windows 专用，默认三次，使用隔离配置
uv run --locked python scripts/qa/benchmark_memory.py --output artifacts/performance/mini.json

# 指定目录版 EXE；同时记录分发目录体积
uv run --locked python scripts/qa/benchmark_memory.py --exe artifacts/performance/dist/coinpilot-ai/coinpilot-ai.exe --output artifacts/performance/exe.json

# 工作台启动内存
uv run --locked python scripts/qa/benchmark_memory.py --workbench --output artifacts/performance/workbench.json

uv run --locked python scripts/qa/benchmark_charts.py
```

原始测量 JSON、截图和图表基准位于 `artifacts/performance/`，属于本机验证产物，不纳入 Git。基准脚本会统计 Windows venv 启动器及其子进程，避免误把约 5MiB 的启动器当成应用内存。
