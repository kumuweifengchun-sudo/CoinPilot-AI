安装前请从系统托盘选择“退出”，关闭正在运行的 CoinPilot AI，包括旧单文件版。关闭工作台窗口只会隐藏窗口，不会退出程序。

本安装包仅为当前 Windows 用户安装，无需管理员权限。

安装和升级不会覆盖个人配置、数据库、图标缓存或 Windows 凭据。旧单文件版使用默认数据路径时，安装版会继续使用这些数据；使用自定义配置路径时，请继续通过原有 --config / --cache-dir 参数启动。

如果旧版已开启开机启动，请在新程序的设置中重新保存一次开机启动设置，让启动项指向安装后的程序。安装器不会自行开启开机启动或改写旧版启动路径。

卸载只移除程序、快捷方式，以及确实指向本安装位置的开机启动项。个人配置、数据库、缓存和凭据将保留。
